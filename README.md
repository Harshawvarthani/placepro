# PlacePro 🚀

PlacePro is a modern full-stack placement preparation platform for students.

## ✨ Features
- Aptitude Preparation
- Coding Practice
- Mock Tests
- Resume Builder
- Interview Preparation
- Analytics Dashboard

## 🛠 Tech Stack
- Next.js
- Express.js
- MongoDB
- Node.js
- Tailwind CSS

## ⚡ Installation

```bash
npm install
npm run dev
